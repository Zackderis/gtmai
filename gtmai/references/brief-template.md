# brief.md template

Ask for this at the very start of every new campaign. It's the safety net if Apollo's Context Center is empty or wrong, and it answers several later questions upfront.

**If the user has no brief:** offer to write one.
1. Ask for their website.
2. Research it (homepage, services, about, case studies, LinkedIn).
3. Fill in the template below, marking anything you couldn't verify with [CONFIRM].
4. Show it, apply the user's corrections, then give them the finished `brief.md` as a downloadable file. Tell them: "Keep this and drag it in whenever you start a new GTMAI campaign."

**Combining it with the Context Center:**
- Use both sources together.
- If they disagree, the brief wins, because it's the user's own words. Mention the conflict in one line.
- If one is missing, use the other.
